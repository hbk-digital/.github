# .github

Organisation-wide default issue forms for hbk-digital.

These forms apply to every repository in the organisation that
does not have its own `.github/ISSUE_TEMPLATE` folder.

## Content rules (this repository is public)
- Templates only. No repository names, project names, client
  information, internal processes or real examples.
- No `profile/README.md`.
- Forms set the issue type only, never labels.
- Changes by pull request, approved by an organisation owner.
